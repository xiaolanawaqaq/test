# 《微尘》30 秒演示脚本

目标：让评委先看到“玩家干预改变环境”，再看到“局部规则产生宏观现象”。
不要使用静态粒子屏保画面，不要把自动化测试数字说成试玩人数。

## 时间线

- **0–2 秒**：开场简介已在首屏（三要素：尘埃是物质、光是能量、毒域是扰动）；
  立即点“放下第一束光”关闭简介，在粒子较密的位置落下光源。
  暖色影响圈、落点冲击波、放光的钟声和近邻粒子亮度立即出现。
  底噪音乐一直在，注意听第 8 秒前后“变亮”的那一下。
- **2–8 秒**：保持画面，让观众看到光源附近的尘埃先聚拢、速度改变，其他区域仍在自由流动。镜头不要切走。
- **8–15 秒**：点击“毒域”，冷色边界与冲击波出现，配一声闷响；局部群体被驱散或改变旋转方向。此处同时出现“漩涡 / 星云 / 流动群落”中的稳定标签——**现象出现的瞬间，上层音乐浮现、提示音响起**。
- **15–22 秒**：换一个位置再放光源，展示同一种子下第二个群落与第一个群落不同。顶部 HUD 保留粒子数、剩余光/毒预算和稳定秒数。
- **22–27 秒**：打开结算，展示实际干预、现象持续时间、峰值、种子、分数，
  以及“对比同种子不放任何东西”的差异行——评委一眼看到玩家干预造成的宏观不同。
- **27–30 秒**：点击“复制战绩”或“同种子重开”，收尾文案为“同一套规则，下一次会长出什么？”

录音时注意：录制版本必须有声音（音乐分层是卖点之一，别静音录制）；
确认“声音”按钮默认开启，简介页停留时也有底噪音乐。

## 录制要求

- 使用 Android 横屏实机或 TapPlay 环境录制；桌面录制只作为开发版补充。
- 首次点击要落在场地内，避免提示因无效点击一直遮挡画面。
- 不旁白解释长规则，只用一句：“我只放光和毒，形状是它们自己长出来的。”
- 同种子重开不是输入回放，文案应说“可确定性重现”，不要说“自动回放”。
